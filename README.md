## 📖 Apa itu Exploit/Scripting?
Dalam konteks ini, **Exploit** adalah perangkat lunak (Executor) yang memungkinkan pengguna menjalankan kode kustom (**Script**) dalam lingkungan game. Script biasanya ditulis dalam bahasa **Lua** untuk mengotomatisasi tugas atau memodifikasi fungsionalitas game secara lokal.
